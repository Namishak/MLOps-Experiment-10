# MLOps Experiment 10: Docker Deployment

## Objective
To package and deploy a Machine Learning application using Docker.

## Tools Used
- Python
- Scikit-learn
- Docker Desktop
- PowerShell

## Implementation
1. Created an ML application using Logistic Regression.
2. Created a requirements.txt file.
3. Created a Dockerfile.
4. Built the Docker image.
5. Ran the Docker container.
6. Tested the containerized application.

## Docker Commands
- docker build -t mlops-experiment-10 .
- docker images
- docker run mlops-experiment-10

## Result
The ML application was successfully packaged
into a Docker image and executed inside a
container with 95.61% model accuracy.
